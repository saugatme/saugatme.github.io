SUPPORTING PROJECT / COMPLETED COURSEWORK

ECG classification with a CNN–Transformer

Exploring signal morphology, sequence modeling and the limits of transferring a model between datasets.

Explore source ↗

Two views of the ECG

This team coursework project studied beat-level classification using LTDB and record-level classification using PTB-XL. Separate models accommodated differences in leads, sampling rates and labels.

Signal processing meets deep learning

The workflow combines bandpass filtering, normalization and beat segmentation with a CNN–Transformer architecture. Convolutions extract local waveform features, while Transformer layers model relationships across the sequence.

ECG signal → Filtering & normalization → CNN features → Transformer → Class predictions

Training beyond majority-class accuracy

The implementation uses weighted sampling to address class imbalance, Gaussian noise and amplitude jitter for augmentation, label smoothing, AdamW and gradient clipping. Macro F1 and per-class results help reveal weaknesses that overall accuracy can obscure.

Reported results & model inspection

The notebook reports approximately 0.63 test macro F1 on PTB-XL. Attention and gradient-based visualizations explore which parts of the signal influence predictions, while confusion matrices expose class-specific errors. These visualizations support investigation rather than proving clinically valid reasoning.

Testing the limits

The evaluation goes beyond the original data split to explore added noise and transfer to MIT-BIH. The supplied assignment materials show that noise robustness did not resolve the cross-dataset performance gap. This makes the work a useful study of evaluation under distribution change, rather than a claim of established generalizability.
