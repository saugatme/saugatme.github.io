Finding clinical information in chest X-ray reports

0.80 reported test macro F1 · Three labels

A chest X-ray comes with a written report. In this assignment, I worked on a model that reads that text and identifies findings such as pneumonia, fluid around the lungs and partial lung collapse.

The problem in plain language

Radiology reports contain useful information, but they are written as free text. This project explored turning that text into structured labels that can be compared and analyzed. It uses the reports associated with medical images rather than examining the image pixels.

How the work fits together

The notebook extracts the findings and impression sections of MIMIC-CXR reports, cleans the text and matches each report to its labels. Reports from one patient stay in the same data split, reducing the chance that the model is tested on someone it already encountered during training.

A bidirectional LSTM reads the text in both directions to build a representation of the report. Its predictions are compared with simpler methods: Naive Bayes and logistic regression using word-based features.

Written X-ray report → Text preparation → Model → Three finding labels → Comparison with reference labels

Reported result

At a prediction threshold of 0.5, the saved BiLSTM test results report a macro F1 score of 0.80, averaging the balance between precision and recall across the three findings. Results vary by finding: F1 is 0.88 for pleural effusion, 0.83 for atelectasis and 0.70 for pneumonia.

The study also includes baseline comparisons and confusion matrices. These help show where errors occur instead of relying on one overall score. It is a coursework text-classification study, not a validated diagnostic tool.

Course context

Completed for Advanced Machine Learning for Data-driven-Health (CM2026) at KTH. The work sits between medical imaging and language processing: learning from what clinicians write about an image.
