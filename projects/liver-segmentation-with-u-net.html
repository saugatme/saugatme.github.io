Teaching a model to outline the liver in CT images

0.8962 best validation Dice

In this assignment, I worked on a model that marks which parts of a CT image belong to the liver. I compared its predictions with reference outlines to see how closely they matched.

What the project does

A CT scan contains many organs and surrounding tissues. The task was to give each image pixel a simple label: liver or not liver. This is called image segmentation. The result is a mask that can be placed over the original image to show the predicted liver region.

How it works

The notebook uses a U-Net, a neural network designed to find regions in images. It first learns broader patterns, then combines them with finer image details to produce an outline.

Before training, the CT images are adjusted to a useful intensity range, scaled consistently and resized. The model learns from individual slices of the scans. All slices from one patient stay in the same training, validation or test group, because nearby slices can look almost identical.

CT image → Consistent image preparation → U-Net → Predicted liver region → Comparison with a reference

What the result means

The best recorded validation Dice score was 0.8962. Dice measures how much the predicted region overlaps the reference region: a score of 1 means a perfect match. This is a validation result used during model development, not an independently reported test score.

Technical details

The implementation uses PyTorch, a two-dimensional U-Net, and a training loss combining binary cross-entropy with Dice loss. The notebook includes training curves and examples showing the CT slice, reference mask and predicted mask side by side.
